## Description

### 1. Adding two numbers in C

To add two numbers in C, you declare variables, use `scanf()` to read the user's input, and apply the `+` (addition) operator to calculate the total.

#### C Source Code

```c
#include <stdio.h>

int main() {
    int num1, num2, sum;
    printf("Enter first number: ");
    scanf("%d", &num1);
    printf("Enter second number: ");
    scanf("%d", &num2);
    sum = num1 + num2;
    printf("The sum of %d and %d is: %d\n", num1, num2, sum);
    return 0;
}
```

#### Expected Output

```
Enter first number: 15
Enter second number: 25
The sum of 15 and 25 is: 40
```
