## Description
In this course, students learn the problem-solving concepts with programming and practice them using the C language.


## Objectives
<!-- Why you will learn C. One line per objective. -->
- Understand the history of computing and how Computer Science reached where it is today.
- Get familiar with computers, their hardware, and the ecosystem around them.
- Learn your first programming language — C — from the ground up.
- Build a problem-solving approach and start thinking like a programmer.
- Meet real engineering problems and learn a beginner-friendly way to solve them.


## Outcomes
<!-- What you can do after learning C. -->
- You will know the basics of computer science advancement and its history.
- You will recognise common CS equipment, jargon, and the wider ecosystem.
- You will have a thorough working knowledge of the C programming language.
- You will be able to break down a problem in a structured, industry-style way.
- You will face new engineering problems with confidence instead of hesitation.


## Prerequisites
- Common sense and logical reasoning
- Basic mathematics


## Units
<!-- Format:  - Unit 1 | Unit title      then  -- one syllabus point per line -->
- Unit 1 | Foundations of Computing
-- Computer hardware, Memory, CPU, Input/Output devices
-- Computer Networks, LAN, File Server, WAN, WWW, GUI/CLI, Ethernet, Wi-Fi, Modem, Switches, Routers, IP Address, Proxy, Gateway
-- Operating Systems, Installation/Uninstallation, Disk/Directory/File system, Application Software

- Unit 2 | C Basics, Operators & I/O
-- Professional Ethics for Computer Programmers
-- Introduction to Computer Languages, Compiling and running a program
-- Problem analysis (requirement analysis, program design), Algorithms, Pseudocode and Flowchart
-- Structure of a simple C program (preprocessor directives, #include and #define, header & library files); Debugging, Testing and Documentation
-- Basic Data Types, Constants/Literals, Expressions, Statements and Comments
-- Operators: Arithmetic, Relational, Logical, Boolean, Ternary, Bitwise, Conditional, Sizeof, Comma; Precedence & Associativity; type conversion
-- Standard Input/Output, Mathematical Functions, Character Functions

- Unit 3 | Control Flow & Arrays
-- Selection Statements (if/else, nested, switch)
-- Loop Structures (while, do/while, for, exit, break and continue)
-- Arrays: 1-D arrays, Passing arguments by value/address, 2-D arrays, Higher dimensional arrays

- Unit 4 | Functions, Strings & Pointers
-- User-defined functions, Storage class and Scope, Macros, Nested and Recursive functions
-- Character Strings: definition and I/O, Null character, String library functions
-- Pointers and Addresses, Address operator, Pointer assignment, Address arithmetic, Chain of pointers, Pointers to array elements, Array of pointers, Pointers as function arguments, Functions returning pointers, Pointers and strings

- Unit 5 | Memory, Structures & Files
-- Dynamic Memory Allocation (calloc(), malloc(), realloc(), free())
-- Structures: Definition & initialization, I/O, Structures as function arguments, Functions returning structures, Array of structures, Nested structures, Unions
-- Pointer to structure; Dynamic data structures: Linked List, Stack, Queue
-- Data Files: I/O statements, Reading data files, End-of-File, Generating data files
