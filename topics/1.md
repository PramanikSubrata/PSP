## Description
To add two numbers in C, you declare variables, use `scanf()` to read the user's input, and apply the `+` (addition) operator to calculate the total.

### C Source Code

```c
#include <stdio.h>

int main() {
    // Declare integer variables for the inputs and the result
    int num1, num2, sum;

    printf("Enter first number: ");
    scanf("%d", &num1);

    printf("Enter second number: ");
    scanf("%d", &num2);

    // Add the two numbers
    sum = num1 + num2;

    printf("The sum of %d and %d is: %d\n", num1, num2, sum);
    return 0;
}
```

### Expected Output

```
Enter first number: 15
Enter second number: 25
The sum of 15 and 25 is: 40
```

### Code Explanation
- `#include <stdio.h>` — pulls in the Standard Input/Output library so `printf()` and `scanf()` work.
- `int num1, num2, sum;` — allocates memory for three integer variables.
- `scanf("%d", &num1);` — reads an integer into the variable's memory address (via `&`).
- `sum = num1 + num2;` — the `+` operator adds the two numbers and stores the result.
- `return 0;` — ends the program cleanly and signals success to the operating system.
